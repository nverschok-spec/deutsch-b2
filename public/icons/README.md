# Иконки PWA

Сюда нужно положить реальные иконки перед деплоем:

- `icon-192.png` — 192×192, обычная иконка
- `icon-512.png` — 512×512, обычная иконка
- `icon-maskable-512.png` — 512×512, с полями под маску (Android adaptive icon)

`manifest.json` уже на них ссылается. Быстрый способ сгенерировать все размеры сразу — https://realfavicongenerator.net/ или `pwa-asset-generator`.
